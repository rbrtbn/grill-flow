# 0029. Message squad agents from their Herdr space

- Status: accepted
- Date: 2026-11-14
- Scope: grill-flow

## Decision
The discussion panel's "To" list offers this question, the run, every running agent in the page
session's Herdr space, and the grill-flow maintainer even while it is down.
Membership is the space (`where` before " / "), since Herdr carries no squad labels; the lead
is the one agent whose parent is outside that set. Lists refresh in the background (10 s).
An `agent:<address>` target is a whole-target thread; the server accepts only addresses on the
current list, so the page never becomes a relay to arbitrary terminals.
Amends 0016: the roster stays display-only; this list is the one place the page addresses
terminals directly. Squad-label rosters can replace the space rule once labels exist.
