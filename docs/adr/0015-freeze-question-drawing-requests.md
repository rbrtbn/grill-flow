# 0015. Freeze question drawing requests

- Status: accepted
- Date: 2026-11-07
- Scope: grill-flow

## Decision
Draw this saves canonical source ownership and exact displayed wording before terminal delivery.
Responses publish typed compare/flow data against the saved request with immutable revisions.
Transport evidence stays separate; interrupted delivery remains visibly unconfirmed.
The page keeps frozen option labels and marks drawings stale when the question changes.
Remote outboxes carry immutable response files validated by the serving host.
This makes drawings useful without changing answers, parsing comments or accepting executable art.
