## Exact guard refusal surface

The hook inspects Claude Bash command text and the reported working directory; it never
executes that command to classify it. It reads no cookie, token, database or runtime settings.
It emits only a fixed reason and safe operation category, never the command or stdin contents.

- Refuse direct HTTP mutation commands naming localhost:4317 or 127.0.0.1:4317, including
  curl explicit POST and data/form options that imply POST, HTTPie POST, and visible
  Python/JavaScript request calls specifying POST. Deny other explicit mutation verbs there
  too. Plain GET health/build/page checks stay allowed; never return cookie headers in tests.
- Refuse command text that attempts to read the checkout's data/token, including relative,
  absolute and home-expanded forms and common cat/head/tail/readFile/open spellings. A metadata
  existence check stays allowed. Do not open or inspect the token to decide.
- Refuse named opens of data/grill-flow.sqlite and its WAL/SHM files unless a narrowly
  recognized read-only open is explicit. sqlite3 default opens and bun:sqlite/SQLite default
  Database opens are refused even for SELECT; explicit sqlite3 -readonly, URI mode=ro and
  recognized readonly Database options may pass. Refuse direct write/redirection/removal of
  those store paths. Read-only `gf events`, `gf state`, `gf grant` and version probes pass.
- Malformed relevant hook input fails closed with a fixed diagnostic. Unrelated commands and
  other tools pass. Ambiguous matching shell text is refused rather than executed or expanded.
  Literal examples in a heredoc may match; fixture tests document that false-positive boundary.

This is the accepted P8 instruction/Claude-hook boundary, not same-user isolation. Indirect
scripts, imported store modules without a named path, variable-built URLs, alternative host
spellings, browser/computer tools, other agents and Codex tools remain outside this text guard.
No protection claim or automatic grant eligibility is inferred from the hook being installed.
