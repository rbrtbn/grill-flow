# Navigation fidelity

The workspace carries through the selected navigation study's quieter presentation:
wordmark and named home destination, underlined header tabs including Updates,
bordered Open/Drafts/All quick filters, and a subdued sidebar inbox. Review & send
stays at the far right. The home label drops the Open for you suffix while its
existing destination remains available.

Question identity, source, round, urgency and answer state sit above the heading,
separated by a rule. Paired previous/next buttons share that row and use the
existing filtered-order navigation and keyboard behavior. Narrow screens wrap the
metadata and controls without clipping either. The former side-arrow gutters are
reclaimed for reading.

Inbox appearance changes leave expiry, unread retention, dismissal and reopening
unchanged. Legacy reading routes retain their overlay notification appearance.
There are no server, storage or delivery changes.

Verification uses scene tests for header routing, question navigation and draft
state, plus static sample-data fixtures with all HTTP blocked. Layout checks cover
regular and expanded discussion, Conversations, collapsed/empty inboxes and active
filters at 1600, 1100, 700 and 430 pixels, including a short phone viewport.
