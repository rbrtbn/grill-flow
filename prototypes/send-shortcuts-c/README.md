# C · Unsent tray and nudge

`http://127.0.0.1:4373/prototypes/send-shortcuts-c/`. Setup: `../send-shortcuts-shared/README.md`.

The header's Review & send becomes an "N unsent" counter. It opens a tray (or press u): drafts
by round with recipients, Send per round, a selection with ⌘↵, ↑↓ and space to choose, and
Keep back (k) for drafts you are deliberately holding, which drop out of the count and the
reminders. Leaving the page with ready drafts asks first (Stay / Leave, keep as drafts / Send
and leave); a quiet minute after answering turns the counter into a nudge (the bar's Idle
nudge skips the wait). The full Review & send page stays one link away for a covering message.
