# A · Send from the queue

`http://127.0.0.1:4371/prototypes/send-shortcuts-a/`. Setup: `../send-shortcuts-shared/README.md`.

Each ready draft in the sidebar has a Send button; each round header has Send N. Either opens
a popover that lists the answers grouped by recipient, then sends on ↵ (esc cancels). Failed
rows turn into Retry. Confirm first, no undo: a delivered answer can't be recalled.
