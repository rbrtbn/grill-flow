# B · Send where you answer

`http://127.0.0.1:4372/prototypes/send-shortcuts-b/`. Setup: `../send-shortcuts-shared/README.md`.

Once a question has a ready draft, a strip under the answer names its recipient and offers
Send this answer (⌘↵) and Send all N in the round (⇧⌘↵). An open question you can't answer
yet offers the round's ready drafts instead, and every strip mentions other rounds' unsent
drafts. A send waits 5 s with Undo (⌘Z) before the page freezes it; after that it is a normal
send. ⌘↵ without a ready draft keeps today's meaning: open Review & send.
